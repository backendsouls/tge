# AI Scripts

This directory contains various scripts generated by AI assistants to automate bulk refactoring and maintenance tasks in the codebase.

## Directory Structure
- `refactoring/`: Contains scripts that rewrite Go code to enforce design patterns, abstract boilerplate using Generics, and update CLI flag parsing.

## Philosophy
These scripts use regular expressions and structural replacement to manipulate the source code. They are saved here so they can be reused or adapted for future mass-refactoring tasks (e.g. adding new fields to domain entities, generating new repositories).
